# Integrations

No external service is connected in this milestone.

Planned integrations, subject to provider availability and user consent:
- Supabase Auth, PostgreSQL and Storage.
- AI provider behind a server-side adapter with explicit private-data consent.
- Calendar providers through supported OAuth/API flows.
- Search/news/RSS sources with source attribution and publication dates.
- YouTube and course/video platforms through permitted embeds and official links.
- Vercel hosting and GitHub source control.

Credentials must be stored in local environment variables or the hosting provider's secret manager, never committed to Git or pasted into public chat.
