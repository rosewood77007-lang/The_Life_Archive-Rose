# User Guide — Initial Shell

This is a review shell only.

- Use the left navigation to switch between primary destinations.
- Select any of the eight departments to open its workspace shell.
- Use the sun/moon control to switch dark and light themes.
- Use Search to navigate between currently known destinations. It does not search saved user content yet.
- Use Quick Capture to write a temporary note. It is held in memory for the current page session and will disappear after refresh.
- On narrow screens, use the floating menu control to open/close navigation.

Do not store sensitive information in this milestone. There is no login or persistent storage yet.
